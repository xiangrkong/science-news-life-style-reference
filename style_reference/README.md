# Science News Life Writing Style Reference

This folder stores an English-language style reference derived from the latest articles on the Science News **Life** topic page:

<https://www.sciencenews.org/topic/life>

## Update policy

- Check the topic page once per week.
- Review only newly published or materially changed pages.
- Record source URLs, publication dates, and the retrieval date.
- Extract stylistic patterns; do not reproduce substantial source text.
- Keep `STYLE_GUIDE.md` concise and actionable. Put detailed evidence in `observations/`.

## Using the guide

Choose a mode for each editing request:

- **Light edit:** preserve the author's voice and structure; fix clarity, grammar, flow, and precision.
- **High-fidelity rewrite:** restructure and recast the prose to follow the guide closely while preserving facts and intent.

Always preserve factual claims unless the user explicitly asks for fact checking. Flag uncertainty instead of inventing details.
