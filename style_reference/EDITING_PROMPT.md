# Reusable Editing Prompt

Use `STYLE_GUIDE.md` as the governing style reference.

## Light edit

Edit the supplied English text for grammar, clarity, precision, concision, and flow. Preserve the writer's organization, voice, facts, emphasis, and level of certainty. Apply the Science News Life style guide only where it improves readability. Return the edited text followed by a brief list of material changes.

## High-fidelity rewrite

Rewrite the supplied English text using the abstract characteristics in the Science News Life style guide: an engaging but restrained opening, an early statement of the central finding, accessible explanations, short purposeful paragraphs, evidence-led progression, calibrated uncertainty, and explicit caveats. Preserve all facts and intent. Do not copy or closely echo source wording. Return the rewrite followed by a brief list of structural and stylistic decisions.

## Adaptive mode

Choose light edit or high-fidelity rewrite based on how much intervention the draft needs. State the selected mode in one line, then provide the edited text and a brief rationale. If factual support is missing, flag the gap rather than inventing information.
